# Phase 0: The Absolute Basics

**WEEKS 1–2**

These projects are tiny. The goal is not to learn a lot, but to **prove to yourself you can finish something**. Each should take 15–30 minutes.

**Before you start:** install Python 3.12+, Git, and a code editor (e.g. VS Code), and create a GitHub account. Learn the basics of `git init`, `add`, `commit`, and `push` — every gate below depends on them.

| **Project** | **What it teaches** | **What you actually build** |
| --- | --- | --- |
| **1. Random Quote Printer** | `print()`, lists, `random.choice()` | A script that prints a random quote from a hardcoded list. |
| **2. Name Greeter** | `input()`, f-strings, variables | A script that asks your name and greets you. |
| **3. Temperature Converter** | Functions, `float()`, arithmetic, error handling | A script that converts Celsius to Fahrenheit and vice versa. |
| **4. Password Generator** | `random` and `string` modules, loops | A script that generates a random password of a given length. |

## GATE

You have four GitHub commits (one per script) and can explain every line of each script.
